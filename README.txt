MILESTONES — KINGDON & TASKER UPDATE

These are replacement folders for the existing GitHub Pages repository.

1. Open your milestones-nfc-test repository on GitHub.
2. Replace the contents of the existing kingdon folder with everything in this package's kingdon folder.
3. Replace the contents of the existing tasker folder with everything in this package's tasker folder.
4. Do not change the land-army folder.
5. Commit the changes.
