MILESTONES LAND ARMY NFC TEST

FILES
- index.html       The mobile visitor webpage
- land-army.mp3    The audio recording

GITHUB PAGES QUICK SETUP
1. Create a new PUBLIC GitHub repository, e.g. milestones-nfc-test.
2. Upload index.html and land-army.mp3 to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose: Deploy from a branch.
5. Choose branch: main and folder: / (root), then Save.
6. Wait for GitHub to publish the site and copy the HTTPS address it gives you.
7. Open that address on another phone and test the Play control.
8. Write that HTTPS address to your NFC tag as a URL/URI record.
9. Also make a QR code from the same address for a visitor fallback.

IMPORTANT
Mobile browsers generally do not allow a webpage to start audio automatically after an NFC tap. The visitor should tap the visible Play control.
